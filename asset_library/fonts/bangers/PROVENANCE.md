# Font: Bangers

Sound-effect lettering font chosen in the comic style guide (variant 2, Lettering;
`docs/design/comic/style-guide-variant-2.md`). Licensed under the SIL Open Font License 1.1;
the licence text from the same source sits next to the font as `OFL.txt`.

The files are the official Google Fonts release files, downloaded unchanged from the
`google/fonts` repository on 2026-11-15 by the operator of the swarvex runner that worked on
task #331, and handed to the agent (Claude Code, model claude-opus-5-5) because the sandbox has
no internet. Both files match the git blob IDs that
`google/fonts` lists for them at the commit below. The font is not modified, converted or
renamed.
